# Veylora environment variable manifest — NAMES ONLY

Source: Vercel project `veylora-fintech-ai-trading` (team `shahabedinmalek-4518s-projects`), read 2026-10-15.
Values are not recorded here and must never be printed, committed or echoed. Names only.

Variables: 179 distinct names across 354 environment-scoped entries.
Of those, 159 are `ALCHEMY_*` (per-network RPC URLs plus the shared app id/key):
- Development: 159
- Preview + Production: 159

A name listed under several scopes exists as a separate entry per scope in Vercel.

## Configuration status

- The `ALCHEMY_<NETWORK>_RPC_URL` set exists in **all three scopes**, so a rebuilt
  Preview or Production deployment has RPC for every configured network.
- When a new network is enabled, add its `ALCHEMY_<NETWORK>_RPC_URL` to all three
  scopes as well, or that chain silently loses RPC in that environment.
- The Neon/Postgres set and the core secrets span Preview and Production.
